## 📖 About This Course

Welcome to the ultimate AI and Data Science course! This repository contains all the lectures, notes, and materials for our comprehensive bootcamp. Whether you're looking to change careers or just level up your skills, you'll find everything you need right here.

We will cover:
* **Python Programming:** From the basics to advanced functions and libraries.
* **Data Analysis & Visualization:** Mastering Pandas, NumPy, Seaborn, and Plotly for Exploratory Data Analysis (EDA).
* **Essential Mathematics:** Building a strong foundation in Linear Algebra, Statistics, and Number Theory.
* **Machine Learning:** Implementing algorithms from scratch and with Scikit-learn, including Linear/Logistic Regression, SVMs, Decision Trees, and Ensemble Methods (Random Forest, XGBoost).
* **Portfolio Building:** Creating real-world projects to showcase your skills to employers.

## 🚀 Getting Started

### Prerequisites

* A computer (Windows, Mac, or Linux).
* A strong desire to learn. No prior programming or data science experience is required!
* A laptop buying guide is included in **Lecture 3**.

### Installation & Setup

1.  **Clone this repository:**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git](https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git)
    cd YOUR_REPOSITORY_NAME
    ```

2.  **Install Software (Covered in Lecture 2 & 5):**
    * We primarily use **Anaconda (Conda)** to manage our environments.
    * Our main IDE will be **VS Code**.

3.  **Create Your Conda Environment:**
    * All lectures will be run in a dedicated Conda environment to avoid conflicts.
    ```bash
    conda create -n ai_bootcamp python=3.10
    conda activate ai_bootcamp
    ```

4.  **Install Required Libraries:**
    * A `requirements.txt` file may be provided, or libraries will be installed as needed.
    ```bash
    pip install pandas numpy matplotlib seaborn plotly scikit-learn jupyter ydata-profiling
    ```
