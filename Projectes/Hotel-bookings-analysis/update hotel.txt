if WIDGETS_AVAILABLE:
    def interactive_hotel_explorer(hotel_type='All Hotels', metric='adr', top_n=10):
        # 1. Filter data
        if hotel_type == 'All Hotels':
            data = df_clean.copy()
        else:
            data = df_clean[df_clean['hotel'] == hotel_type].copy()

        # 2. Process metrics
        if metric == 'adr':
            plot_data = data.groupby('country_name')['adr'].mean().sort_values(ascending=False).head(top_n)
            title = f'Top {top_n} Countries by ADR (€) - {hotel_type}'
            colorscale = 'Viridis'
            label = 'ADR (€)'
        elif metric == 'revenue':
            plot_data = data.groupby('country_name')['revenue'].sum().sort_values(ascending=False).head(top_n)
            title = f'Top {top_n} Countries by Total Revenue - {hotel_type}'
            colorscale = 'Greens'
            label = 'Revenue (€)'
        elif metric == 'cancellation':
            # Calculate cancel rate per country
            c_data = data.groupby('country_name').agg({'is_canceled': ['sum', 'count']})
            c_data.columns = ['canceled', 'total']
            c_data = c_data[c_data['total'] >= 50] # Minimum sample size
            plot_data = (c_data['canceled'] / c_data['total'] * 100).sort_values(ascending=False).head(top_n)
            title = f'Top {top_n} Countries by Cancel Rate (%) - {hotel_type}'
            colorscale = 'RdYlGn_r'
            label = 'Cancel %'
        else: # Bookings
            plot_data = data['country_name'].value_counts().head(top_n)
            title = f'Top {top_n} Countries by Total Bookings - {hotel_type}'
            colorscale = 'Blues'
            label = 'Bookings'

        # 3. Create the Plotly Figure
        fig = go.Figure(data=[
            go.Bar(
                x=plot_data.values,
                y=plot_data.index,
                orientation='h',
                text=plot_data.values,
                texttemplate='%{text:.2s}',
                textposition='outside',
                marker=dict(
                    color=plot_data.values,
                    colorscale=colorscale,
                    showscale=True,
                    colorbar=dict(title=label),
                    line=dict(color='#2C3E50', width=1)
                )
            )
        ])

        fig.update_layout(
            title=title,
            xaxis_title=label,
            yaxis_title='Country',
            yaxis={'categoryorder':'total ascending'}, # Keep top values at the top
            plot_bgcolor='#F8F9FA',
            height=500,
            margin=dict(l=150, r=20, t=50, b=50)
        )

        # IMPORTANT: This line makes the plot show up in the interactive output
        fig.show()

    # Define widgets
    hotel_w = widgets.Dropdown(options=['All Hotels', 'City Hotel', 'Resort Hotel'], description='Hotel:')
    metric_w = widgets.Dropdown(
        options=[('ADR', 'adr'), ('Revenue', 'revenue'), ('Cancel Rate', 'cancellation'), ('Bookings', 'bookings')],
        description='Metric:'
    )
    n_w = widgets.IntSlider(value=10, min=5, max=20, description='Top N:')

    # Display dashboard
    out = interactive(interactive_hotel_explorer, hotel_type=hotel_w, metric=metric_w, top_n=n_w)
    display(out)

### Part 2: Missing Value Strategy

**Business Logic Over Statistical Imputation**

My approach rejects blind mean/median filling in favor of **domain knowledge**.

| Column | Missing % | Strategy | Business Reasoning |
|--------|-----------|----------|-------------------|
| **children** | 0.01% | Fill with **0** | Missing = no children declared |
| **country** | 0.05% | Fill with **'Unknown'** | Minor data collection gap |
| **agent** | 15.80% | Fill with **0** | Direct booking (no intermediary) |
| **company** | 94.47% | **DROP COLUMN** | 94% null = useless for analysis |

**Why Not Use Mean/Median?**

For categorical business data:
- A booking either has an agent or doesn't (no "average agent")
- Missing children ≠ "average of 0.12 children"
- Logical defaults beat statistical imputation

**Columns Dropped:**
- `company` (94% null)
- Original `meal` and `country` (replaced by mapped versions)

### Part 3: Feature Engineering

**Creating Decision-Making Metrics**

I'm not just cleaning - I'm **manufacturing business intelligence**.

**New Features Created:**

1. **total_nights** = `stays_in_weekend_nights` + `stays_in_week_nights`
   - **Why:** Hotels care about total occupancy duration
   - **Use:** Segment long-stay vs. short-stay guests

2. **revenue** = `adr` × `total_nights`
   - **Why:** The ultimate business KPI
   - **Use:** Identify high-value segments

   - **Why:** Validates booking integrity (must be > 0)
   - **Use:** Filter invalid records

   - **Why:** Identify family segment
   - **Use:** Targeted marketing, amenity planning

5. **customer_segment** = "Family" or "Non-Family"
   - **Why:** Simplifies family vs. non-family analysis
   - **Use:** Revenue comparison, cancellation patterns

6. **lead_time_category** = 4 booking windows
   - **Why:** Different cancellation risks by planning horizon
   - **Categories:** Last Minute (0-30), Short (31-90), Medium (91-180), Long (180+)
   - **Use:** Risk-based deposit strategies

**Business Value Unlocked:**

## 📊 STEP 5: OUTLIER MANAGEMENT (CAPPING)

### The Winsorization Technique

**What is Capping?**

Instead of **deleting** extreme values, I **cap** them at the 99th percentile threshold.

**Visual Example:**

```
Original ADR Distribution: [€10, €50, €100, €200, €500, €1000]
After Capping at 99th %ile (€240): [€10, €50, €100, €200, €240, €240]
```

**The €1,000 booking is preserved at €240** - still recognized as premium, but not distorting statistics.

---

### Why This Matters for Resort Hotels

**Scenario:** A presidential suite books at €500/night.

| Method | Action | Consequence |
|--------|--------|-------------|
| **IQR Deletion** | Remove booking | Lose luxury segment insights |
| **Winsorization** | Cap at €240 | Preserve "premium" signal without distortion |

**Business Impact:**

Luxury bookings inform:
- **Pricing Strategy:** What premium guests will pay
- **Amenity Planning:** What high-value guests expect
- **Marketing:** Where to find affluent customers

**Deleting them would:**
- Underestimate revenue potential by €50K-100K
- Miss high-margin opportunities
- Bias analysis toward budget travelers
